# GO-TAROT · ChatGPT(Codex) 디자인·인터랙션 지침서

> 이 문서는 ChatGPT(Codex)가 GO-TAROT 모바일 웹앱을 **더 화려하고 완성도 있게** 다듬을 때 따르는 지침이에요.
> 코드 구조, 데이터, 암호화, 배포는 Claude가 맡고 있어요. ChatGPT는 **그림, 디자인, 애니메이션, 인터랙션, 교차 검증**을 맡아요.
> 작업을 시작하기 전에 이 문서를 끝까지 읽어 주세요. 특히 **2장 "레퍼런스 이미지 읽는 법"**은 꼭 지켜야 해요.

## 1. 글과 말투 규칙 (화면에 새 글자를 넣을 때)

- **제목·소제목은 명사로 끝내요.** `~다`, `~요`, `~까`로 끝나는 제목은 쓰지 않아요.
  - ✅ `오늘의 카드`, `수정구슬`, `절벽 끝의 첫걸음`
  - ❌ `타로, 그림으로 읽다`, `오늘의 카드를 뽑아요`
- **설명 문장은 다정하고 친근한 존댓말**이에요. 과장하거나 느끼한 표현은 빼요.
  - ✅ `카드를 한 장씩 눌러 뒤집어 보세요.` / `아직 공부하지 않은 카드예요.`
  - ❌ `운명의 문이 당신을 기다리고 있답니다~♡` / `신비로운 세계로 초대합니다!!`
- 버튼은 짧은 동작 단어로: `입장하기`, `펼쳐 보기`, `다시 섞기`

## 2. 레퍼런스 이미지 읽는 법 ⚠️ 가장 중요

레퍼런스 이미지는 `docs/references/` 에 있어요. **레퍼런스는 "분위기와 구조를 참고하라"는 뜻이지, "이 이미지를 사이트에 넣어라"는 뜻이 아니에요.**

### 2-1. 모든 레퍼런스에 공통으로 지킬 것

1. **레퍼런스 파일을 사이트에 그대로 넣지 마세요.** `<img src="docs/references/...">`, CSS 배경, `assets/` 복사 모두 금지예요.
2. **레퍼런스 안의 글자를 옮기지 마세요.** `AT&T`, `TRAVEL`, `We pursue a relaxed gaming experience`, `Verification code sent!`, `enter the code`, `Confirm your email`, `refero.design.team@gmail.com`, `IL SOLE`, `Soft Birch` 같은 글자는 레퍼런스의 일부일 뿐이에요.
3. **휴대폰 껍데기는 디자인이 아니에요.** 목업 속 아이폰 테두리, 노치, 상태 표시줄(9:41, 배터리), 홈 바는 만들지 마세요.
4. **아이폰 시스템 키보드는 만들지 마세요.** E·F 레퍼런스 아래쪽 숫자 키패드(1 2 3 / ABC DEF…)는 운영체제가 띄우는 키보드예요. 접속코드는 영문+숫자라서 **실제 입력은 기기 키보드로** 받아요. 화면 안에 가짜 키패드를 그리면 안 돼요.
5. **그림을 따라 그리지(트레이싱) 마세요.** 구도·재질·색감만 참고하고, 새로 그려 주세요.
6. 레퍼런스의 **영문 서체**(세리프 영문 제목 등)는 분위기만 참고해요. 한글은 `--font-display`(송명), `--font-body`(고운바탕)를 써요.

## 4. 화면별 작업 — 화려하게 만들 것

각 항목의 **완료 기준**을 만족하면 끝이에요. 모든 효과는 `prefers-reduced-motion: reduce`일 때 꺼지거나 아주 짧아져야 해요.

### 4-1. 수정구슬 인트로 (가장 중요)

지금 구현: 버건디 밤하늘 + 금별 반짝임 + 회전하는 기하 도형 + CSS로 그린 수정구슬과 받침대 + 12칸 코드 입력. 글자를 넣을수록 구슬 안 안개가 밝아지고(`--power` 0→1), 맞으면 빛이 터지며 앱으로 넘어가고, 틀리면 구슬이 흐려지며 흔들려요.

다듬을 것:
1. **구슬 안 안개를 살아 있게**: `<canvas>` 또는 SVG 필터(`feTurbulence` + 애니메이션)로 구슬 안에서 천천히 소용돌이치는 연기. `#orb`의 `--power` 값(0~1)을 읽어 밝기·속도를 올려 주세요.
2. **구슬을 받쳐 든 손 일러스트**(D·I 레퍼런스 분위기): 새로 생성한 그림을 `assets/public/intro-hands.webp`로. 잠금 전 공개 화면이라 **직접 생성한 그림만** 돼요. CSS의 `.orb-stand`를 대신하거나 뒤에 겹쳐 주세요.
3. **글자 하나 넣을 때마다**: 해당 칸에서 금가루가 구슬 쪽으로 빨려 들어가는 파티클.
4. **성공 연출**: 구슬 중심에서 빛이 화면 전체로 번짐 → (G 레퍼런스처럼) 붉은 커튼이 양옆으로 걷히며 앱 등장. 전체 1.5초 이내. 끝나면 반드시 `#intro`에 `hidden`이 붙어야 해요(지금 `enterApp()`이 처리).
5. **실패 연출**: 구슬 안이 검붉게 흐려지고 금이 가는 듯한 선이 잠깐 비쳤다가 사라짐.
6. **기억된 기기**: 칸 없이 `입장하기` 버튼만 보이는 상태도 같은 품질로.

완료 기준: 375px에서 스크롤 없이 한 화면에 들어옴 / 중급 안드로이드에서 끊김 없음(애니메이션은 `transform`·`opacity` 위주) / 키보드가 올라와도 입력칸이 가려지지 않음.

### 4-2. 상단 메뉴와 목차

- `☰ 목차` 패널이 열릴 때 항목이 위에서부터 차례로 내려오는 스태거 애니메이션
- 지금 보는 페이지 항목에 금색 표시가 미끄러지듯 이동
- 완료 기준: 열기·닫기 0.3초 이내, Esc·바깥 터치로 닫힘 유지

### 4-3. 카드 목록과 카드 페이지

- 카드 목록: 화면에 들어올 때 카드가 덱에서 한 장씩 놓이는 등장 효과
- 카드 페이지(`#/card/<id>`, 카드마다 각각의 페이지): 들어올 때 카드가 뒤집히며 앞면 공개, 좌우 스와이프로 이전·다음 카드로 넘길 때 카드가 옆으로 밀려나는 전환
- 카드 그림이 들어갈 자리: `.tarot .art` (파일 이름 `major-00`~`pentacles-14`)
- J 레퍼런스처럼 카드 페이지 상단에 장식 테두리(새로 그린 SVG)
- `🐾 마법 삼림 해석` 스위치를 켜고 끌 때 해당 블록이 접히듯 사라지는 전환

### 4-4. 이야기 읽기

- **버전 토글(로맨스 판타지 / 역사 블로그)**: 바꿀 때 책장이 넘어가거나, C 레퍼런스처럼 별가루가 흩날리며 글이 바뀌는 전환
- 위쪽에 읽은 만큼 차오르는 얇은 진행 막대
- 삽화(`figure.ill`)는 스크롤로 화면에 들어올 때 살짝 떠오르며 나타나기
- N 레퍼런스처럼 **글자 크기·배경(종이/밤) 바꾸기** 작은 설정 버튼

### 4-5. 홈

- 오늘의 카드: 처음엔 뒷면, 눌러야 뒤집혀 공개(H 레퍼런스처럼 손에 든 구도도 좋아요)

## 5. 그림 — 삽화, 카드 그림, 아이콘

이미지 내려받기는 사용자가 미리 허락했어요(규칙은 `AGENTS.md`). 넣는 곳은 `assets/images/`, 출처는 `assets/credits.json`.

### 5-1. 이야기 삽화

- **요청문**: 빌드하면 `illustration-prompts.md`가 생겨요. 화풍 스케치 `docs/references/STYLE-A-romance.webp`(로판), `STYLE-B-blog.webp`(역사 블로그)를 기준으로 삼아요. 토큰을 아끼려고 첫 메시지 한 번 + 장면 한 줄씩 보내는 방식이에요.
- **목록**: 빌드하면 `illustration-list.md`가 생겨요. 파일 이름, 이야기 속 위치, 장면 설명이 다 적혀 있어요. ⬜인 것부터 그려 주세요.
- **규격**: 가로 4:3, 1200 × 900px, `webp`, 300KB 이하
- **로맨스 판타지 버전** (`ill-romance-*`): 로맨스 판타지 웹소설 삽화 느낌. 부드러운 수채·디지털 페인팅, 따뜻한 빛
  - **세미**: 20대 중반 한국인 여성. 어깨까지 오는 짙은 갈색 웨이브 단발, 앞머리, 크고 동그란 눈. 기본 옷은 크림색 블라우스에 버건디 리본과 버건디 치마. 카드마다 그 카드의 옷을 입기도 해요(예: 0번 바보의 보따리와 흰 장미)
  - **피터**: 타로의 요정, 키 큰 청년. 나뭇잎 그림자 같은 짙은 녹갈색 머리, 반투명하게 빛나는 잠자리 같은 날개, 세이지 녹색과 금색 장식의 옷. 장난스럽지만 다정한 표정. 16장 이후 날개 한쪽 끝이 그을렸다가 에필로그에서 나아요
  - 두 사람의 생김새는 모든 삽화에서 같아야 해요. 첫 장을 그린 뒤 그 모습을 기준으로 삼아 주세요
- **까마귀 로판 버전** (`ill-crows-*`): 머더 오브 크로우 덱 분위기. **누렇게 바랜 종이 위 검은 잉크만** 쓰는 흑백 고딕 판화(색은 쓰지 않거나, 아주 옅은 세피아까지). 피터는 검은 깃털 망토의 청년이거나 까마귀 모습. 세미는 위와 같은 생김새. 머더 오브 크로우 카드 그림(코라도 로이 작)은 **따라 그리지 마세요**(저작권). 장면 설명의 구도만 따르고 새로 그려 주세요
- **역사 블로그 버전** (`ill-blog-*`): 빈티지 판화·콜라주 + 손글씨 메모 스타일. 찢긴 종이, 화살표·동그라미 메모, 비교 그림 나란히 놓기
- **카드 속 장면을 그릴 때**: 1909년 라이더 웨이트 스미스 원판의 구도(인물 자세, 소품)는 참고해도 돼요(미국 퍼블릭 도메인). 마법 삼림 덱 그림은 **그리지 마세요**(저작권).

### 5-2. 카드 그림 (`major-00` ~ `pentacles-14`)

- 1909년 패멀라 콜먼 스미스 **원판 스캔**(위키미디어 커먼스 등)은 써도 돼요. 단, 최근에 다시 색칠한 판(예: Universal Waite 등)은 저작권이 있으니 쓰지 마세요
